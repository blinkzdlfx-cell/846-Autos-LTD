# Scope — 846 Autos Demo

**Status: Living Draft**

## Demo must demonstrate
- Premium responsive homepage
- Animated hero
- Automatic hero image transitions
- Animated headline/word transitions
- Services presentation
- Vehicle showcase
- Clearing & forwarding presentation
- Car wash presentation
- Lounge/bar presentation
- Snooker presentation
- Visual gallery
- About/company information
- Contact/CTA
- Mobile navigation
- Responsive layouts
- Accessibility states
- Basic SEO metadata
- Performance-conscious image handling

## Possible enhancements
- Vehicle detail view
- Gallery filtering
- Advanced scroll choreography
- Page transitions
- Interactive service cards
- Google Maps
- Social links
- PWA-style caching

These are candidates, not commitments.

## Explicitly deferred
Database, API, authentication, admin dashboard, payments, online bookings, customer portal, vehicle checkout, inventory management, AI assistant, CMS.

## Scope principle
If a feature does not materially improve the owner's ability to understand or evaluate the proposed website, prefer leaving it out of the first demo.
