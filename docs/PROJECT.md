# Project Definition — 846 Autos Demo

**Status: Living Draft**

## Purpose
Create a polished premium website demo that presents 846 Autos Limited as more than a conventional car dealership. The first goal is demonstration, not a complete production platform.

## Working business model
1. Vehicle sales
2. Clearing & forwarding
3. Car wash
4. Lounge / bar
5. Snooker
6. Additional services to be confirmed

This list is provisional. Do not turn assumptions into factual claims.

## Experience goal
Premium, modern, confident, automotive-oriented, visually immersive, responsive, fast, and professional without unnecessary complexity.

## Homepage direction
A large visual hero may include automatically transitioning images, animated headline text, controlled word/letter transitions, strong CTAs, and responsive mobile treatment. Exact copy, imagery, animation sequence, and layout remain open for refinement.

## Working homepage order
Hero → Introduction → Services → Vehicles → Clearing & Forwarding → Car Wash → Lounge/Bar → Snooker → Gallery → Contact/CTA → Footer.

The order is not final.

## Technical boundary
Frontend-only demo. No database, API/backend, authentication, payments, admin dashboard, customer accounts, booking engine, or vehicle checkout.

Static/local data may demonstrate the UI, but it should be structured so it can later be replaced by real data.

## Future direction
If approved by the owner, this demo can evolve into a production website. Production architecture should be decided later rather than prematurely implemented here.
